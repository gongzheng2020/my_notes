## 常量

**常量是固定值，在程序执行期间不会改变**。可以使用 `const` 关键字或使用 `#define` 宏定义。  **`const` 定义的常量有类型信息，较为推荐。**
``` c
const int MAX = 100;          // 整型常量
const float PI = 3.14159;    // 浮点型常量
const char NEWLINE = '\n';   // 字符常量（转义字符）
```

常用的转义字符如下：
- `'\n'`：换行
- `'\t'`：水平制表符
- `'\\'`：反斜杠
- `'\''`：单引号
- `'\0'`：空字符（字符串结束标志）

字符串常量表示为`char myString[] = "Hello, world!";`

## 运算符

- **逻辑运算符**：`&&`（与）, `||`（或）, `!`（非），支持短路求值。
- **位运算符**：`&`（按位与）, `|`（按位或）, `^`（按位异或）, `~`（按位取反）, `<<`（左移）, `>>`（右移）。
- **其他运算符**：`sizeof`（计算类型或变量字节大小）, `?:`（三目运算符）, `&`（取地址）, `*`（解引用）, `->`（指针访问成员）, `.`（直接访问成员）

``` c
int a = 5, b = 10;
int sum = a + b;           // 算术运算符 +，sum = 15
int isEqual = (a == b);   // 关系运算符 ==，isEqual = 0（假）
int result = a &lt;&lt; 1;      // 位运算左移，result = 10（相当于 a * 2）
a++;                       // 后缀自增，a 变为 6
int max = (a > b) ? a : b; // 三目运算符，max = b = 10
```

## 类型转换

将一个变量的类型转换为另外一个类型

- 隐式类型转换

``` c
int i = 10;
float f = 3.14;
double d = i + f; // 隐式将int类型转换为double类型
```

- 显式类型转换

``` c
double d = 3.14159;
int i = (int)d; // 显式将double类型转换为int类型
```

## 变量

- 可以同时初始化多个变量

``` c
int d = 3, f = 5;           // 定义并初始化 d 和 f
```

- `extern`表示只声明而不定义变量（不建立存储空间）
- 左值与右值
	- 左值：**指向内存位置的表达式**被称为左值（lvalue）表达式。左值可以出现在赋值号的左边或右边。
	- 右值：**指的是存储在内存中某些地址的数值**。右值是不能对其进行赋值的表达式，也就是说，右值可以出现在赋值号的右边，但不能出现在赋值号的左边。

## 存储类

存储类定义 C 程序中变量/函数的存储位置、生命周期和作用域。

- **auto** 存储类是所有局部变量默认的存储类。随函数结束而被销毁。
- **register** 存储类用于定义存储在寄存器中而不是 RAM 中的局部变量。可以增加访问速度，但因为不在RAM中所以无地址。
- **static**
	- 可以在函数调用之间**保持局部变量的值**
	- 修饰全局变量时，**全局变量的作用域限制在声明它的文件内**
- **extern** 存储类用于提供一个全局变量的引用
