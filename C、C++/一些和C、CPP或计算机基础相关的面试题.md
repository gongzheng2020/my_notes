1. Q：用过哈希表吗？介绍一下
A：它是一种**通过哈希函数将键映射到数组索引**从而实现平均O(1)时间复杂度的插入、删除和查找的数据结构。

2. Q：`volatile`是什么？
A：volatile提醒编译器它所修饰的变量随时都有可能改变，表示**禁止编译器对变量的读写进行优化**，确保每次访问都直接操作内存，最典型的场景就是硬件寄存器的相关操作。

3. Q：ISR与main的共享变量为何要用`volatile`？
A：因为如果不使用`volatile`进行修饰，在代码经过编译阶段优化后，main可能会直接将变量值缓存在寄存器中，导致ISR中虽然修改了变量在内存中的值，但main读取的还是寄存器中的旧值。

4. Q：栈溢出
A：堆栈溢出的**根本原因是栈空间有限**，而**递归过深或局部变量过大导致栈帧超出限制**。核心思路是：减少栈帧数量（递归改迭代）和减少单个栈帧大小（大数据放堆上）。

4. Q：字节对齐与结构体对齐
A：32位CPU一次性只能读取4字节数据，为了可以一次性读取完数据，可以在变量值之间**填充字节**，让数据的起始地址能被4整除。结构体对齐的意思是按照内部各变量所占空间大小按从大到小（或从小到大）的顺序定义，就能让结构体所占空间最小。**注意其规则是大小为最大对齐成员（基础类型） 大小的整数倍。**
```C
// 这个是1字节
typedef struct {
    char a:4;
    char b:4;
} S1; 
// 这个是8字节
typedef struct {
    char a;
    int b;
} S1; 
```

5. Q：讲一下冒泡排序流程
A：重复遍历一整个数列，每次比较两个数，位置错误就交换过来

6. Q：static关键字
A：static修饰的局部变量会放在静态存储区，只会被初始化一次，而且不会因为函数结束而被销毁；修饰全局变量或函数的话就会限制它们仅当前文件可用，避免命名冲突；在类中的静态变量被所有该类的对象共享(无this指针)，为防止冲突只能在类外进行定义(类名::)，静态类函数由于没有this指针，因此只能访问其他静态成员，静态类限制类的作用域只在本文件。

7. Q：C++内存分布
A：栈、堆、静态\全局区（**.data**已初始化、**.bss**未初始化）、常量（只读）区（**.rodata**）、代码区

8. Q：什么是内存碎片
A：内存碎片分为外部和内部两种。外部碎片是指内存只剩下多个不连续的小空间；内部碎片是指为程序分配的内存块过大而造成浪费。解决方法包括优先使用静态分配、减少内存申请/释放次数、使用合并策略等。

9. Q：嵌入式中内存泄漏和内存碎片的区别是什么？如何预防？
A：内存泄漏指的是申请内存空间后没有进行释放，或逻辑错误导致丢失了对该内存的引用，出现野指针，会造成空闲内存越来越少，直到申请失败导致系统崩溃；资源使用完毕后要及时释放、使用静态数组或内存池替代、使用智能指针。内存碎片指的是程序在运行中频繁地分配和释放**大小不一**的内存块，导致原本连续的空闲内存被切割成许多不连续的小空间，当再需要申请一块较大的连续空间时就会失败；优先采用静态内存分配、采用分页机制将内存划分为若干个固定大小的块。

10. Q：数组和链表的区别
A：数组是大小固定，在内存中连续存储的，访问速度快但执行插入删除操作比较麻烦；链表的大小不固定，在内存中不连续，其插入删除操作比较高效（改指针即可），但内存开销大、访问慢。

11. Q：队列和链表的区别？各自举一些例子
A：队列是一种采用FIFO处理数据的规则；链表是一种存储数据的结构，其在内存中是非连续的，由一个个节点构成。队列可以用于一些需要排队处理的场景，比如说打印机、浏览器中的前端任务等；链表可以用于需要不定长且频繁插入删除的场景，比如说操作系统中的任务管理、管理浏览器历史记录等。

12. Q：共享内存了解过吗？
A：将同一块物理内存映射到不同进程的虚拟地址空间中。这样，不同的进程就可以通过操作自己的虚拟地址来访问和操作同一块物理内存，从而实现数据交换。

13. Q：线程、进程、协程的区别？
A：进程是资源分配的基本单位，每个进程拥有独立的虚拟地址空间，进程间资源是完全隔离的；线程是CPU进行调度的基本单位，每个线程共享进程的代码、数据段和堆，但拥有自己独立的栈（Stack）和寄存器上下文；一个进程可以包含多个线程；协程和线程类似，但其是在用户空间进行调度的，因此资源开销小。

15. Q：vector扩容，resize和reserve的区别？
A：resize修改的是Vector的大小，而reserve修改的是容量。容量指的是这个vector最多能容纳多少元素，而大小指的是实际已经容纳了几个元素。如果当前大小与容量相等就会触发vector的扩容机制，会重新申请一块大内存空间，再将旧空间内的数据迁移并删除旧空间。

15. Q：虚函数及其底层原理？构造函数可以是虚函数嘛？
A：虚函数是指在基类中使用关键字 virtual 声明的函数，它允许子类重写它，从而在运行时调用子类的重写版本，实现动态绑定；每个包含虚函数的类在编译时会生成一个虚函数表（vtable），存储该类所有虚函数的地址，调用虚函数时，对象通过虚函数指针（vptr）找到函数地址，从而实现动态调用 。不能，因为虚函数指针是在构造函数执行期间才被初始化的。

16. Q：简单介绍一下socket套接字，以及客户端和服务端创建流程
A：socket是内核提供给应用层的网络通信抽象——把「IP + 端口 + 传输层协议」封装成一个 fd，应用通过它收发数据。
TCP服务端：socket() -> bind() -> listen() -> accept()（阻塞等待） -> read/write -> close()
TCP客户端：socket() -> connect()（主动发起三次握手，阻塞等待握手成功） -> read/write -> close()
UDP服务端：socket() -> bind() -> recvfrom()（阻塞等待） -> sendto() -> close()
UDP客户端：socket() -> sendto() -> recvfrom() -> close()

17. Q：堆和栈分别是什么？
A：栈（Stack）是操作系统自动管理的内存区域，用于存放局部变量、函数参数和返回地址；堆（Heap）是程序员手动管理的内存区域，用于动态分配的变量。

18. Q：说明一下map和unordered_map
A：`map` 底层是红黑树（有序），`unordered_map` 底层是哈希表（无序）。

18. Q：C++ 程序的编译过程
A：首先是预处理阶段，处理头文件、宏、条件编译等，产物为`.i`；接下来是编译阶段，生成汇编代码`.s`；接下来是汇编阶段，将汇编代码转换成可重定位目标文件`.o`；最后是链接，将各个c、cpp文件生成的`.o`文件以及库文件（`.a`、`.so`）合并起来，输出最终的可执行`.elf`

19. Q：智能指针有哪几种？智能指针是什么？本质是什么？
A：unique_ptr、shared_ptr、weak_ptr，智能指针本质上就是类模板，内部持有对象指针并自动管理其生命周期（重载了解引用和成员访问操作符），本质是利用析构函数在对象过期时自动删除所指向的内存

20. Q：C++的三大特性
A：C++的三大特性是**封装**、**继承**和**多态**。
**封装**：将变量和函数绑定在一起，对外隐藏内部实现细节，只暴露必要的接口。
**继承**：允许子类拥有父类的属性和方法，并可以在此基础上扩展或重写功能。
**多态**：同一个接口（比如同一个函数名），在不同的对象上会有不同的行为表现，比如函数重载或虚函数。

21. Q：extern、strlen、sizeof关键字。
A：extern用于声明变量或函数是外部链接的，让编译器在另外的文件中查找；strlen用于计算以 \0 结尾的字符串不包括\0的长度，如果没有\0，则会发生错误；sizeof计算的是变量或类型占用的内存总字节数。

22. Q：堆区申请内存除了malloc还有哪些接口。
A：还有calloc（自动将申请的区域清零）、realloc（用于调整已申请内存大小）、kmalloc（分配的是一块物理地址连续的内存）、kzalloc（分配的是一块物理地址连续的内存，并清零）。

23. Q：TCP的time_wait的影响。
A：TCP中的time_wait是发生在四次挥手阶段的，主要是为了保证最后一个ACK可靠送达，并且防止旧数据包污染新连接；但是如果有大量短连接，由于每个短连接都存在time_wait状态，会在短时间内占用大量端口和内存，浪费服务器资源，当超过系统可分配的端口范围时，服务器将无法正常进行连接，出现假死现象。
