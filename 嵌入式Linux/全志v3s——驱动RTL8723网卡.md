# 一、修改Linux内核配置

首先清除先前配置，并加载默认配置：

``` sh
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- distclean
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- licheepi_zero_defconfig
```

在linux内核根目录运行`make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- menuconfig`，添加对网卡的相关支持：

![[Pasted image 20260727225507.png]]

![[Pasted image 20260727225937.png]]

然后再进行编译：

``` sh
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- -j6
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- INSTALL_MOD_PATH=out modules_install
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- dtbs
```

编译完成后，在drivers/staging/rtl8723bs目录下生成r8723bs.ko文件：

![[Pasted image 20260727230316.png]]

# 三、使用工具测试

前述操作只是确认了网卡及其驱动是否工作正常，本节我们通过buildroot生成含有`wireless tools`和`wpa_supplicant`这两个工具的rootfs，并用其测试是否能连接正常连接wifi。

使用`make menuconfig`命令修改buildroot配置再重新编译，并解压至第二分区：

![[Pasted image 20260729204742.png]]

接下来按照以下步骤连接测试网络：

1. 挂载wifi模块，并打开wlan0:

``` sh
insmod r8723bs.ko
ifconfig wlan0 up
```

2. 配置连接wifi， 编辑vi /etc/network/interfaces文件。

``` sh
auto lo
iface lo inet loopback

auto wlan0
iface wlan0 inet dhcp
```

3.  在开发板根目录下/etc 目录下创建一个名为“wpa_supplicant.conf”的配置文件，此文件用于配置要连接的 WIFI 热点以及 WIFI 密码：

``` sh
ctrl_interface=/var/run/wpa_supplicant
ctrl_interface_group=0
ap_scan=1
network={
    ssid="gz"
    scan_ssid=1
    key_mgmt=WPA-EAP WPA-PSK IEEE8021X NONE
    pairwise=TKIP CCMP
    group=CCMP TKIP WEP104 WEP40
    psk="123123123"
    priority=5
}
```

4. wpa_supplicant.conf 文件编写好以后再在开发板根文件系统下创建一个`/var/run/wpa_supplicant`目录

``` sh
mkdir /var/run/wpa_supplicant -p
```

5. 一切准备好以后就可以使用 wpa_supplicant 工具让 RTL8723BS 连接到热点上，然后使用指令检查网络状态，命令如下：

``` sh
wpa_supplicant -B -c /etc/wpa_supplicant.conf -i wlan0
udhcpc -i wlan0
wpa_cli -iwlan0 status
ping www.baidu.com
```

![[Pasted image 20260730152830.png]]

接下来设置开机自动连接wifi：

1. 新建一个rc.local文件到/etc/init.d目录下：

``` sh
!/bin/sh

sh /etc/init.d/auto_wifi_link.sh
echo "wifi finish!!"
```

2. 创建脚本auto_wifi_link.sh放到/etc/init.d/目录下：

``` sh
#!/bin/sh
modprobe /r8723bs.ko
ifconfig wlan0 up
wpa_supplicant -B -c /etc/wpa_supplicant.conf -i wlan0
sleep 3s
udhcpc -i wlan0
```

3. 修改开机启动项 vi /etc/inittab ，在`# now run any rc scripts` 后加入如下：

``` sh
::sysinit:/etc/init.d/rc.local
```

![[Pasted image 20260730155944.png]]

4. 修改rc.local权限后其就可以正常工作了：

``` sh
# chmod 755 /etc/init.d/rc.local
```


5. reboot重启看到自动导入驱动然后连接wifi得到ip地址:

![[Pasted image 20260730155805.png]]
