所谓创建交叉编译环境，其实就是将交叉编译器下载、解压到某个文件夹，再将这个文件夹地址设置一个全局变量，来让我们自己的程序可以找到并调用它。

对于ARM处理器而言，常用的有两种编译器：

- **32位ARM**：选择 `gcc-arm-linux-gnueabihf`。

- **64位ARM (AArch64)**：选择 `gcc-aarch64-linux-gnu`。

>其中gnueabihf中的hf代表“hard float”（硬浮点），适用于带有FPU（浮点运算单元）的ARM设备，性能更好。

# 1、包管理器下载

安装：`sudo apt install gcc-arm-linux-gnueabihf g++-arm-linux-gnueabihf`

验证是否安装成功：`arm-linux-gnueabihf-gcc -v`

# 2、手动下载

包管理下载的编译器版本通常是固定的，我们可以手动下载以支持不同版本。

具体可以参考[这篇博客](https://blog.csdn.net/p1279030826/article/details/105021536)。

首先下载并解压[工具链](https://developer.arm.com/-/cdn-downloads/permalink/legacy-linaro-gnu-toolchains/4.9-2017.01/gcc-linaro-4.9.4-2017.01-x86_64_arm-linux-gnueabihf.tar.xz)(路径不要有中文)：

``` sh
wget https://developer.arm.com/-/cdn-downloads/permalink/legacy-linaro-gnu-toolchains/4.9-2017.01/gcc-linaro-4.9.4-2017.01-x86_64_arm-linux-gnueabihf.tar.xz
sudo tar -vxf gcc-linaro-4.9.4-2017.01-x86_64_arm-linux-gnueabihf.tar.xz
```

接着设置环境变量：

``` sh
1、打开编辑~/.bashrc 文件
sudo vim ~/.bashrc
2、在最底部添加以下内容
export PATH=$PATH:/home/gz/文档/v3s/tools/gcc-linaro-4.9.4-2017.01-x86_64_arm-linux-gnueabihf/bin
3、使环境变量立即生效
source ~/.bashrc
```

安装其他必要的库：

``` sh
sudo apt-get install lsb-core lib32stdc++6
```

使用`arm-linux-gnueabihf-gcc -v`命令查看是否安装成功：
